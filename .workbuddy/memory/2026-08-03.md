## 飞行棋棋子改成双圆环 + 飞机剪影

2. 内层细描边圆环（同色，BasicStroke = outerRing/3）
3. 白色中心区域
4. 彩色飞机剪影（Path2D 绘制，4 个不同朝向）

### 飞机 path 设计（机头朝上）
- 机身：圆头垂直椭圆（fillOval）
- 主翼：两片大三角（fillPolygon，左右对称、后掠）
- 尾翼：两片小三角（fillPolygon，左右对称）
- 机头：深色小圆点

改用 fillOval + fillPolygon 组合（替代之前的复杂 Path2D），轮廓更清晰、更像经典飞行棋棋子。

### 4 个玩家飞机朝向
```java
double[] ROT = { -PI*3/4, PI/4, -PI/4, PI*3/4 };
// 0(红,右下基地)→左上  1(黄,左上基地)→右下  2(蓝,左下基地)→右上  3(绿,右上基地)→左下
```
即"每个玩家飞机朝自己基地对面的方向（朝中心飞）"。用 `Graphics2D.create() + translate + rotate` 隔离坐标系，绘制完 dispose 还原。

### 关键技巧
- `g3 = (Graphics2D) g2.create()` 隔离坐标系避免 rotate 影响后续绘制
- `bodySize = ir*2 - 4` 留出内圈空间
- `Math.max(2, bodySize/14)` 等自适应小棋子尺寸

## 飞行棋补充游戏规则：同色跳格 + 起飞虚线

按用户详细规则描述，在 `AeroChessGame.java` 中实现三套规则：

### 规则1：同色跳格
- 摇完骰子移动后，如果落到和自己棋子颜色一样的格子，跳到外圈顺时针方向下一个同色格子
- 用扫描方式找下一个同色格（非简单 +4，因起点格插入导致间隔 4-5 格不等）

### 规则2：起飞虚线
- 起飞线 progress=19，虚线终点 progress=32（顺时针跳 13 步）
  - 蓝(3,4)→(4,10)  黄(4,11)→(10,10)  绿(11,10)→(10,4)  红(10,3)→(4,4)
- **摇骰子后到起飞线**：起飞到终点 → 再跳到下一个同色格子
- **同色跳格后到起飞线**：起飞到终点 → **不**接着跳格

### 规则3：异色叠机阻挡
- 所有跳棋前提：当前同色格与下个同色格之间（不含两端）不存在异色叠机
- 异色叠机 = 2 架及以上棋子在同一格，且颜色不完全相同（Set.size() >= 2）

### 代码实现
- `FLY_FROM_STEP` 从 4 改为 19（原值错误）
- 删除旧 `checkFlyLine` 方法，新增 5 个方法：
  - `postMoveCheck(color, pieceIdx, prog, isAfterJump)`：移动后规则检查入口
  - `trySameColorJump(color, pieceIdx)`：同色跳格（扫描找下一同色格）
  - `doTakeoff(color, pieceIdx)`：起飞虚线（p=19→p=32）
  - `hasHeteroStackBetween(color, fromProg, toProg)`：异色叠机检测
  - `cellColorAtKey(cellKey)`：cellKey→格子颜色
- `movePiece` 中 `checkFlyLine` 调用改为 `postMoveCheck(..., false)`

### 验证
独立测试类验证（已删除）：
- 4 色起飞线起点 p=19 格子颜色全部同色 ✓
- 4 色起飞线终点 p=32 格子颜色全部同色 ✓
- 各色同色格子分布一致：0,2,6,10,15,19,23,27,32,36,40,45,49,53（14 个/色）

## 飞行棋添加机器人 AI 自动回合

按用户反馈"机器人是不是没动啊，我都看不到它摇的骰子"，添加完整的机器人 AI 逻辑。

### 问题根因
AeroChessGame.java 里完全没有机器人 AI：endTurn 切换到机器人后 isMyTurn 返回 false、按钮禁用，但没有任何代码触发机器人行动，机器人就卡住了。之前的开发只关注真人玩家交互，机器人只是占位。

### 解决方案（新增 4 个方法 + 1 个辅助方法）

1. isBot(name)：判断名字是否以"机器人"开头
2. maybeStartBotTurn()：refreshUI 末尾调用，检测当前玩家是机器人则用 javax.swing.Timer 延迟 800ms 触发 botRollDice
3. botRollDice()：用 dicePanel.roll 复用骰子动画（用户能看到点数），动画结束后 callback 处理游戏逻辑；摇到 6 且有棋子在场上进度>40 移动场上棋子，否则起飞新棋子
4. botChooseMove(color)：AI 策略选进度最大的棋子（最接近终点）
5. notifyEvent(msg, title) 辅助方法：真人回合弹 JOptionPane，机器人回合只更新 statusLabel（非阻塞）

### 弹窗改非阻塞
机器人回合时弹 JOptionPane 会模态阻塞，机器人连续触发跳格+起飞会卡住。替换的弹窗：
- checkCollision 击落提示
- trySameColorJump 跳格成功（异色叠机阻挡的弹窗只对真人弹）
- doTakeoff 起飞提示

### 完整链式调用
refreshUI → maybeStartBotTurn → 800ms 延迟 → botRollDice → 骰子动画 600ms → callback → botChooseMove → movePiece → postMoveCheck → trySameColorJump / doTakeoff / checkCollision → endTurn 或 refreshUI（摇到6时）→ 链式继续

### 验证
预览用 3 机器人 + 1 真人，等 5 秒截图：骰子显示点数 3、棋盘上散落 3 个不同颜色的机器人棋子、状态栏显示机器人行动消息（非阻塞）、真人玩家回合按钮可用。全部通过。
